# Good Rocket — дизайн текущей версии

## Композиция

Один графитовый холст и четыре полноэкранных слайда без шапки и видимой полосы прокрутки. Точки справа показывают текущий слайд и переключают его. Колесо и жест переключают ровно по одному слайду. При перезагрузке открывается первый слайд.

1. Слоган «ОТ ИДЕИ К РЕЗУЛЬТАТУ», одно предложение об услугах, спокойная кнопка обсуждения и анимированная ракета.
2. «Примеры наших работ»: три карточки с ноутбуком или телефонами. Нажатие открывает подробности в модальном окне.
3. Короткое описание команды, рабочий стек и перечень форматов, которые команда может разработать.
4. Контакты: равные колонки с открытыми ссылками на Telegram и email слева, компактное поле с готовым шаблоном сообщения справа.

Перед первым слайдом показывается `goodrocket.ru`, набираемое по буквам. За слайдами работает `AmbientFlow` — одобренная владельцем фоновая анимация. Её не менять при обычной работе над следующими слайдами.

## Визуальный язык

- Графит `#191a18`, светлый текст `#f2f0e9`, жёлтый акцент `#efb62f`.
- Geologica для заголовков; Golos Text для текста и элементов управления. Шрифты лежат локально в `public/fonts/`.
- Ширина контента до 1440 px, адаптивные боковые поля.
- Крупные заголовки, короткие абзацы, немного акцентного цвета.
- При `prefers-reduced-motion` движения отключены или сокращены.

## Проверка

Основные стили находятся в `src/studio.css`. Сборка `npm run build` проверяет типы и создаёт готовый HTML. Браузерную проверку владелец проводит на своём локальном сервере; отдельный превью-сервер не запускать.
