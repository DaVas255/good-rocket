## Что важно сохранить

- Не менять `AmbientFlow` без отдельной просьбы: текущий вариант утверждён.
- Не запускать дополнительный превью-сервер: владелец запускает сайт локально.
- Текущие экраны аналитики созданы для портфолио, показатели на них иллюстративные. Не добавлять вымышленные измеримые результаты в текст.
- Пока не добавлять следующие слайды: сначала согласовать их содержание.
- В папке проекта нет репозитория Git, поэтому промежуточное состояние записано в этом файле без коммита.
