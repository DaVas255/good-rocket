# Good Rocket

Сайт команды разработки на React, TypeScript и Vite. Сейчас это четыре полноэкранных слайда: первый экран, примеры работ, рассказ о команде и контакты. Переключение колесом, жестом, клавиатурой или точками навигации. Перед первым экраном показывается короткая загрузочная сцена. Фоновая анимация находится в `src/components/AmbientFlow.tsx`.

## Локальная работа

Подходит Node.js 20.19+ в ветке 20.x или 22.12+.

```bash
npm ci
npm run dev
npm run build
```

`npm run build` проверяет TypeScript, собирает клиент и заранее добавляет содержимое React в `dist/index.html`. Для публикации на статическом хостинге нужен только `dist/`. Команда `npm run preview` доступна, но в работе над проектом её не запускаем по просьбе владельца.

## Где что менять

- `src/App.tsx` — порядок слайдов и модальные окна.
- `src/components/Projects.tsx` и `ProjectDialog.tsx` — карточки и подробности трёх работ.
- `src/components/SlideNavigation.tsx` — список слайдов и переключение.
- `src/studio.css` — оформление и адаптивные состояния.
- `src/config/site.ts` — Telegram и email команды.
- `public/projects/` — медиа проектов. Экраны сервиса аналитики созданы для портфолио; данные на них иллюстративные.
- `index.html`, `public/robots.txt`, `public/sitemap.xml` — метаданные и адрес `goodrocket.ru`.
- `public/og.png` — обложка ссылки; `scripts/generate-og.ps1` — её генерация.

Текущее состояние, принятые решения и следующие шаги записаны в [PROJECT_STATE.md](PROJECT_STATE.md). Домен и публикация пока не настроены.
